# Rio-Seco-OPS
Rio Seco OPS transforma dados em ação para salvar vidas no Amazonas. Com monitoramento dos rios, mapas inteligentes e gestão logística, a plataforma identifica comunidades isoladas pela seca e otimiza a entrega de água, alimentos e medicamentos, conectando tecnologia, agilidade e esperança a quem não pode esperar.
